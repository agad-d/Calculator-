# 🧮 Game Zone — Calculator

A simple and beginner-friendly **web calculator** built using HTML, CSS, JavaScript, and Bootstrap.

This project was created to practice building an interactive user interface and working with JavaScript functionality.

## ✨ Features

- 🔢 Basic arithmetic operations
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 💯 Percentage
- 🔙 Backspace button
- 🗑️ Clear / AC button
- ➕➖ Positive/negative number button
- 🔢 Decimal number support
- 📱 Responsive interface using Bootstrap

## 🛠️ Technologies Used

- **HTML5** — Structure of the calculator
- **CSS3** — Styling and layout
- **JavaScript** — Calculator functionality
- **Bootstrap 5.3.8** — UI utilities and responsive styling
